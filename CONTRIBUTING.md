# Contributing

Contributions should preserve Reach Signal’s central boundaries: uncertainty visible beside every estimate, named methods with their limits, no causal claims the design cannot support, and fictional demo data only.

Before submitting a change:

```bash
python -m pytest
python -m ruff check .
python -m build
```

Use fictional or openly licensed test data. Do not contribute proprietary course material, customer or respondent data, or third-party content without clear redistribution rights.
